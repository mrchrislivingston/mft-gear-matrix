# MFT Gear Matrix System Overview

## Core Systems

### Matrix
- Gear-based interval training system
- Structured by modality (Run, Echo Bike, etc.)
- Progress tracked via pace ranges

### Gear System (Run V1)
- 8 fixed gears
- Each gear defines:
  - work duration
  - rest duration
  - interval count

### Workout Flow
Gear → Workout → Intervals

### Principle
- No scoring
- No coaching interpretation
- Only structured tracking of performance over time
